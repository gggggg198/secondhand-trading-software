# 软件工程实验一：校园二手交易系统需求分析

本仓库保存当前访谈版本的第一次完整 AI 需求输出及对应记录，供后续人工审查、设计与实现使用。本次实验只进行需求分析。

## 文件

- `requirements.md`：32 条首版需求，包含来源、业务规则、异常处理和验收方法。
- `chat.txt`：两轮带编号的李、刘需求对话，以及本次实际 AI 整理提示词和完整输出。李负责了解与整理需求，刘是需求提出方。

输入对话保留原有的模拟性质说明，首版需求暂为待确认；本仓库不将 AI 初稿视为已经完成的人工审查。

## 版本标记

`lab1-ai-draft` 固定当前这一轮的 AI 初稿。标签创建后不得移动、删除或覆盖。

后续在同一需求文件中进行审查修订，并向 `chat.txt` 追加实际沟通与审查记录。全部完成后另行创建 `lab1-final`，保留初稿以供对照。

公开仓库至少保留至课程结束。
