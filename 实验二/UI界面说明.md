# 小蓝鲸二手集市 UI 设计

小蓝鲸二手集市面向校园单件二手交易。访客浏览可预约商品，普通账号可收藏、发布或预约商品，管理员负责审核、违规处置和权限管理。画板以 1440 像素宽的当前网页为基准，保留页面完整高度。账号、价格、日期和照片均为演示数据。

在 Chrome 或 Edge 中打开[网页原型](web/index.html)。演示账号可操作收藏、商品、审核和预约。数据保存在当前浏览器。[网页打开与操作说明](web/README.md)

在 draw.io 中打开[可编辑原型](UI设计/小蓝鲸二手集市_UI原型.drawio)，底部标签对应 22 个画板。文字、表格、标签、按钮、图表和图片可独立编辑。画板基于网页的演示状态重建，选定的导航和按钮链接到相关场景，实际操作在网页原型进行。配套 [PNG](UI界面/) 由 draw.io 渲染，文件名与画板一致。

深蓝用于标题和管理侧栏，亮蓝用于主操作，浅蓝至青绿用于首页背景，暖橙突出价格。分类与预约状态同时使用颜色和文字区分，收藏通过空心及实心爱心区分。

## 典型使用流程

1. 访客在 01 选择机械键盘，进入 02。通过「登录后预约」进入 03，选演示买家后进入 07。04 演示普通账号注册。
2. 买家在 07 提交交付约定，在 08 查看预约 R-0434。卖家通过 09 核对原约定和确认截止后接受，买家经 10 确认收到实物，11 展示成交记录。该组画板使用同一笔预约。
3. 12 展示提交结果未知时按原请求恢复。13 展示另一买家抢先预约后的冲突。21 展示超过确认截止的预约 R-0435 和原交付约定。
4. 管理员在 14 核对 P-1090 的待审快照，15 演示对 P-1074 封禁时联动取消 R-0433 的确认提示。
5. 在 01 或 02 点爱心可以收藏，22 展示可预约收藏和已不可预约条目。关注量随当前收藏关系变化。取消收藏后列表移除该条目。

已在 draw.io 查看器点验 01 → 02 → 03 → 07 → 08 → 22 的跳转。

## 状态、权限与反馈

| 场景 | 界面行为 |
| --- | --- |
| 待审核、已发布和已预约 | 待审核显示“撤回审核”。已发布且无有效预约显示“下架”。已预约行提示当前占用，卖家可从预约处理入口办理后再按最新状态下架。 |
| 预约双方的可用动作 | 待卖家确认时，买家可以取消，卖家可以接受或填写原因拒绝。卖家已确认时，双方取消均需原因，只有当前预约的买家显示“确认交付完成”。终态保留原约定和历史结果。 |
| 私有交付信息 | 公开详情显示商品及卖家，不展示具体交付地点和时间。预约详情面向本单买卖双方和获授权管理员。管理员查看后记录访问，权限由服务端按该预约核对。 |
| 价格或价格区间不合法 | 就地提示“价格需在 ¥0.01–¥100000.00 之间，最多两位小数”或“最低价不能高于最高价”，焦点回到对应字段并保留输入。 |
| 收藏与关注量 | 登录后可收藏他人已发布商品。每账号每商品至多计一次，取消收藏使关注量减一。商品不可预约时，已收藏者仍可在「我的收藏」取消。 |
| 页面状态变化 | 提示“商品或预约状态已变化，请刷新后再操作”。已有有效预约时显示 13 的冲突提示，下架或封禁后引导返回集市。 |
| 截止时间已到 | 当前待确认预约失去接受入口，显示过期原因与可执行的下一步。已确认预约超过交付时间时可提醒双方。 |
| 服务暂不可用 | 已知未执行时提示“服务暂不可用，请稍后重试”。提交结果未知时展示 12，通过本次请求查询结果，取得明确状态后再决定是否发起新操作。 |

实现时，登录按用户名、密码和登录按钮的顺序获得焦点。查询按关键词、分类、最低价、最高价、重置、筛选按钮和结果项组织键盘访问。预约按交付时间、地点和提交按钮组织焦点。标签和错误文案随控件可读，状态同时使用文字与颜色。关键词匹配范围、日志的时间端点和分页仍按实验一待确认事项处理。
