## 可以操作的流程

1. **预约与交付。** 在集市选「75 键机械键盘」，以买家登录并填写交付地点。提交后切换到卖家，在「我的预约 → 我收到的预约」接受预约。切回买家，打开同一条预约，勾选已收到实物并确认交付。商品状态会更新为已售出。
2. **发布与审核。** 卖家从「我的商品」新建商品、保存草稿或提交审核。管理员在「商品审核」查看当前提交并通过或驳回。通过后可在集市筛选到该商品。
3. **异常结果。** 提交预约时展开「演示响应丢失」并勾选。提交后点击「查询本次结果」，页面会取回原预约。用另一位买家在商品状态已变化后提交，可查看冲突反馈。
4. **管理与统计。** 管理员可封禁商品、查看平台预约及交付详情、管理账号权限和查询操作记录。卖家可以查看自己的操作记录与成交统计。
5. **收藏商品。** 登录后点击其他卖家商品卡片或详情里的爱心，可收藏或取消收藏。从主导航进入「我的收藏」。关注量按当前收藏该商品的账号数计算，每个账号对每件商品计一次。收藏的商品被预约或下架后，列表会提示当前不可预约，并提供取消收藏。

页面使用浏览器本地演示数据，角色、商品及预约会随操作更新。演示服务的权限和事务状态仅用于验证页面行为。实际项目仍需接入后端接口、真实认证与 PostgreSQL。关键词目前匹配标题和描述，图片在本地保存缩小后的预览。演示日期范围采用北京时间，成交统计含起点、不含终点。

收藏按演示账号保存在当前浏览器。新演示数据预置了几条收藏记录，已有的本地数据会保留并从空收藏开始。

若浏览器设置限制本地文件访问，可在本目录用 PowerShell 运行以下命令，然后打开 [本地网页](http://127.0.0.1:8000/)。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

通过本地文件和 HTTP 打开时会使用各自的浏览器存储。浏览器限制本地文件存储时，页面会使用当前窗口内的演示数据。[浏览器存储说明](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)
